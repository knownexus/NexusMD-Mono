Where should the resize handle appear?

When hovering over a calendar event, how do you indicate it can be resized?

A

Bottom grip bar

A small, visible grip bar appears at the bottom edge on hover. Dragging it extends or shrinks the event. Same pattern as Google Calendar.

B

Bottom edge only — cursor change

No visible grip. The cursor changes to s-resize when hovering near the bottom edge of an event. Cleaner look, but less discoverable.

9:00 – 9:30
↕ cursor appears on bottom 8px
C

Top + bottom grips

Grip bars at both top and bottom. Top drag moves the start time (shrinks/grows from top), bottom drag moves the end time. Most flexible.
