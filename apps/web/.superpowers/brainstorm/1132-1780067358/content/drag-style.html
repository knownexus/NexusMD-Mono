How should the event behave while dragging?

When you grab a calendar event and drag it vertically, what do you see?

A

Live move — event follows cursor

The event block moves with your cursor in real time. The original slot is left empty. A small tooltip shows the new time (e.g. "10:30 AM") as you drag.

Stand-up ↕10:30
B

Ghost + drop target

A faded "ghost" stays at the original slot while a solid preview snaps to the nearest time slot as you hover. Drop to confirm. The ghost shows where it was, the preview shows where it'll go.

Stand-up (original)
Stand-up → 10:30
C

Simple — just move it

No ghost, no live preview. Drag and the event snaps to the nearest slot on drop. Clean, no extra chrome. Works well if snap intervals are obvious (every 30 min).
