# Icon Theming Design Spec
**Date:** 2026-06-15

---

## 1. Tray icon adapts to Windows dark/light mode

### Goal
The system tray icon switches between a dark variant (for light taskbars) and a light variant (for dark taskbars) based on the Windows system theme, and updates live when the user changes their OS theme.

### Assets
- `assets/tray-icon.png` — existing dark icon (dark-blue `#1e3a5f`); serves as the dark variant (used when taskbar is light)
- `assets/tray-icon-light.png` — **new** white (`#ffffff`) version of the same icon (used when taskbar is dark)

The light variant is generated by updating `scripts/create-icons.js` to output a second 32×32 PNG with `currentColor` replaced by `#ffffff` instead of `#1e3a5f`. The script already has `sharp` wired up and renders the mark SVG — this is a two-line addition. Run `npm run icons` to regenerate all assets including the new light tray icon.

### tray.js changes
Export a second function `updateTrayIcon(tray, isDark)` that sets the tray icon based on the `isDark` flag:

```js
function updateTrayIcon(tray, isDark) {
  const name = isDark ? 'tray-icon-light.png' : 'tray-icon.png';
  const iconPath = path.join(__dirname, '..', 'assets', name);
  let icon = nativeImage.createFromPath(iconPath);
  if (icon.isEmpty()) icon = nativeImage.createFromDataURL(FALLBACK_ICON);
  tray.setImage(icon);
}
```

`createTray` accepts an `isDark` parameter and calls `updateTrayIcon` immediately after construction:

```js
function createTray(win, isDark) { ... }
```

### main.js changes
- Destructure `updateTrayIcon` from the `require('./tray')` import alongside `createTray`.
- Pass `nativeTheme.shouldUseDarkColors` to `createTray` at startup.
- After tray creation, register a `nativeTheme.on('updated', ...)` listener that calls `updateTrayIcon(tray, nativeTheme.shouldUseDarkColors)`.

## 2. UI icon visibility in cobalt theme

### Goal
Icons using `var(--text-subtle)` are nearly invisible in the cobalt (dark) theme. Fixing the token value corrects every affected site in one change.

### Affected elements (all use `--text-subtle`)
- **ProfileMenu dropdown icons** — Light mode, Project Areas, Settings (inline `color: var(--text-subtle)`)
- **Settings modal tab icons** — `.pl-rail-item .ic { color: var(--text-subtle); }`
- **Sidebar section labels** — `.nav-section-label { color: var(--text-subtle); }`
- **User role text** — `.user-role { color: var(--text-subtle); }`

### Fix
In `nexusmd.css`, update `--text-subtle` inside the `[data-theme="cobalt"]` block:

```css
/* before */
--text-subtle:   #3e4d62;

/* after */
--text-subtle:   #56697e;
```

`#56697e` reads as clearly secondary/de-emphasised on cobalt surfaces while remaining legible. It aligns visually with the same "subtle" role that `#a8a08a` plays on light parchment.

## Out of scope
- macOS tray icon (template images handle dark/light automatically on macOS)
- Changing any other icon colors beyond the `--text-subtle` fix
- Generating the light tray icon programmatically (asset must be created manually)
